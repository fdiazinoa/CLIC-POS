# Checklist functional

Cada punto pertinente requiere esperado/observado y enlace a evidencia para candidate SHA. N/A solo si analista propone y validador independiente justifica ausencia de impacto; nunca por falta de entorno. Checklist completada no sustituye ejecución.

- [ ] Registrar SHA, plataforma, empresa de prueba, rol, terminal, config, flags y dataset.
- [ ] Venta: artículo/scan/variante/modificadores/kit, cantidades, tarifa/almacén y totales.
- [ ] Impuestos incluidos/excluidos/exento/múltiples/servicio, descuento línea/global y autorizaciones.
- [ ] Cobro: efectivo/tarjeta de prueba/mixto/moneda/fracciones/crédito, vuelto/saldo, cancel y doble click.
- [ ] Intento proveedor ambiguo: conciliar sin segundo cargo; error no deja éxito falso.
- [ ] Ticket: aparcar/restaurar/histórico/anular/devolver; no reabrir cerrado ni duplicar venta/NCF.
- [ ] Mesas: abrir/editar/guardar/salir, mover total/parcial, destino ocupado/vacío, unir y cobrar/cerrar.
- [ ] Dos terminales: locks/liberación/refresh, concurrent edits y pedidos/KDS.
- [ ] Cierre Z: corte por terminal, efectivo declarado/diferencias, membership/history/secuencia y retry.
- [ ] Impresión/reimpresión/copies/routing/cajón/visor: fallo periférico no repite cargo.
- [ ] Auth: activación/vinculación/takeover fallido/login/supervisor/revocación/resume y permisos por rol.
- [ ] Config/catalog/ERP admin conservan operación local y datos offline.
