# Checklist tickets

Cada punto pertinente requiere SHA/manifest, entorno/rol/flags, esperado/observado y evidencia. No ejecutado = BLOCKED, no PASS.

- [ ] Listado/apertura/edición/restauración/recovery/cobro/cierre y permisos.
- [ ] Parked ticket/history/closed membership coherentes; no reaparece venta perteneciente Z.
- [ ] Tickets unidos/fracciones/devoluciones/anulaciones/restart conservan IDs/qty/saldos.
- [ ] Impresión/reimpresión distinguible, sync retry no duplica; p95 abrir/cerrar.
