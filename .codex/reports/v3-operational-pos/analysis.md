## SYMPTOM / EVIDENCE / ROOT CAUSE

The downloaded V3 snapshot is not yet an operational POS. `LargeMasterSyncV3Authority.ts` hardcodes candidate=false. `App` renders the nonoperational CanaryScreen when its separate lab flag is on; regular POS still receives App's legacy `products`/`config`. #819 OperationalCatalog and #820 CheckoutAuthority have no UI/checkout callers. Thus merges do not establish sales parity.

Confirmed critical flow: POSInterface barcode/text -> addToCart -> proceedToCheckout -> PaymentModal -> handlePaymentConfirm -> transactionService sequence/fiscal -> App.handleTransactionComplete -> ledger/documents -> print/fiscal/background -> Z/history. Partial-payment writes occur before ordinary source checks, so authority validation must precede them. transactionService fallback reads legacy config taxes and can assume 18%; a V3 mismatch must reject before sequence allocation.

App.handleTransactionComplete: ~11321 calls processInventoryDeduction with App legacy products; native/durable path stores transaction/history/ledger, legacy path stores sequentially. ~11395 deferred stock recalculation scans complete legacy ledger/products and never updates V3 balance. inventoryEngine maps direct every sold line to qtyOut, including SERVICE/noninventoriable. Adapter maps all non-SERVICE types to PRODUCT and omits recipe, cost, modifiers/lot/serial details. POS stock checks additionally subtract legacy inventoryCommitments although adapter already subtracts V3 qtyReserved/qtyCommitted. These are real integration gaps, not ERP download corruption.

Inventory snapshot contract exposes only version/cursor/balances; no event coverage or acknowledged movement watermark. APPLIED_ERP or receipt ACK is not evidence the fetched balance includes a particular event. Blind snapshot replacement plus local overlay can double deduct or lose stock. Existing `saveDocumentsAtomically` native boundary allows atomic legacy financial documents without forcing the separate sqlite_outbox_v2 rollout.

Maps read: SYSTEM_MAP, CRITICAL_FLOWS, DEPENDENCY_MAP, SYNC_ARCHITECTURE, OFFLINE_ARCHITECTURE, PERFORMANCE_ARCHITECTURE, RISK_AREAS, CLOUD_ADMIN_DEPLOYMENT. Their audit SHA is historical; relevant claims corroborated against this base. No device/network behavior certified by this static analysis.
