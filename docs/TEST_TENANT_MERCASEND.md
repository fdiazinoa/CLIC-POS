# Tenant de pruebas mercasend-pruebas

Instrucción del propietario, recibida el 18 de octubre de 2026: el tenant `mercasend-pruebas` y todas las empresas que pertenecen a ese tenant están destinados a pruebas. El POS DEMO asociado puede utilizarse para las validaciones necesarias.

Se autoriza realizar pruebas funcionales, de integración y operativas dentro de ese ámbito, con datos y operaciones de prueba. Antes de escribir, comprobar la identidad autenticada del tenant y la pertenencia de la empresa; el nombre de una caja por sí solo no identifica el ámbito. Esta autorización no se extiende a otros tenants ni a empresas ajenas.

Para la entrega fiscal/presentaciones de ERP #2284 y POS #925 siguen vigentes las instrucciones específicas: mantener el flujo nuevo apagado, no instalar migraciones remotas y no reemitir ni duplicar facturas existentes. Las emisiones del ensayo de integración utilizan un proveedor simulado. `bindingEvidence` permanece apagado. Conservar la base y la vinculación del POS durante las validaciones.

Este documento registra el propósito del entorno y la autorización de pruebas; no modifica permisos, guards, configuración o flags de ejecución.
